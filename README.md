# 海智园区订单开票原型

订单开票双端交互原型，含发起端和移动开票端。

## 功能

- 从订单发起单笔或批量开票申请，按商户分别生成申请。
- 个人或企业抬头、选填接收邮箱、二次确认提交。
- 移动开票端查询和处理申请，登记线下开票结果。
- 在线上传、人工线下邮箱发送、仅更新已开票状态。
- 已开票文件独立查看、放大预览与原文件下载。

## 演示边界

使用虚构示例订单和抬头，数据仅保存在当前页面内存中，刷新后恢复。
文件选择用于本地预览，不上传服务器；系统不自动开票或发邮件。
随附PDF为演示样张，不作为真实发票或报销凭证。

## 运行与依赖

通过HTTP静态服务器或GitHub Pages打开index.html。
PDF预览使用本地打包的PDF.js及字体、字符映射和WASM资源，许可见vendor/pdfjs/LICENSE和各资源许可文件。
